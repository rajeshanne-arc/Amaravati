About this site & its data

This is an unofficial viewer, not a land record. Nothing shown here creates, proves or transfers any right in land. For any legal, financial or registration purpose, verify every plot with the official APCRDA viewer at gis.apcrda.org/lps and with APCRDA / the Sub-Registrar's office.

Where the data comes from

All plot data is read from the Andhra Pradesh Capital Region Development Authority's public GIS service (APCRDAGIS/LPS_Plot). A snapshot is taken automatically every night at about 03:00 IST and published here; individual plot lookups additionally query APCRDA's server live when it is reachable. The snapshot date is always shown in the site's footer. Zoning colours follow APCRDA's own published palette.

Change history

Each night's snapshot is compared with the previous one. Any change to a plot's allottee, zone, extent, registration code or registration date is appended to a permanent log and shown in that plot's record under History. Entries are never edited or removed, and the underlying version history preserves every past snapshot as a second permanent record. Tracking covers changes from the date the log began — earlier changes are not recoverable from the public service.

Names and privacy

Allottee names appear exactly as APCRDA publishes them on its own public viewer; this site adds no information of its own. Land allotment registers are public records, and showing them supports the scheme's transparency. If a name or plot detail appears wrong here, first check the official viewer — if the error exists there too, report it to APCRDA; if it appears only here, it will be corrected by the next nightly refresh, since this site republishes rather than edits. Requests concerning this site's copy of the data can be raised on the project's GitHub repository.

How to read a plot record

  • Plot code (e.g. 25-778-4644-30-C30) is APCRDA's identifier; the registration code is the longer form used in registration documents.
  • Zone letters: R = residential, C = commercial, I = industry, P = parks and open space, S = institutional (government, education), U = reserve.
  • Boundaries show what adjoins the plot on each side — a neighbouring plot (tap to open it) or a road/zone description.
  • Extent is shown exactly as recorded by APCRDA, without unit conversion.

Accuracy limits, honestly stated

  • Plot outlines are drawn from coordinates in APCRDA's data; a small number of records in the source have inconsistent locations, and the site skips these from map fits.
  • Owner grouping is by name as recorded — two different people with the identical recorded name will appear as one; the same person spelled two ways will appear as two.
  • The register may be up to one day behind the official service between nightly refreshes.
